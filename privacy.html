Privacy Policy

Last updated: November 8, 2026

Oracle is a personal tool run by Jeff Fusco on his own computer. It accesses only the Google accounts of its owner.

Data accessed

With the owner's consent, Oracle uses Google APIs to read and write the owner's Google Sheets, Google Docs and Google Drive files, and to read the owner's Gmail messages.

How data is used

Data is used only to produce the owner's personal reports and notes. It is stored only on the owner's computer and in the owner's own Google account.

Sharing

Data is not sold, shared with third parties, or used for advertising.

Oracle's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.
